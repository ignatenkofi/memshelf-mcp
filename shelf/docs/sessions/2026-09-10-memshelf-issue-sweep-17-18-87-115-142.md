## Digest
Ночная смена закрыла все пять открытых issue memshelf-mcp: #115 (PR #140), #87 (PR #141), #18 (PR #143), #17 (PR #144), #142 (PR #145, продолжение #81). Главный результат — семантический сайдкар: model2vec potion-multilingual-128M, индекс вне полки в ~/.local/state, RRF-слияние с grep, kill-switch MEMSHELF_SEMANTIC=off, extra memshelf-mcp[semantic], CLI memshelf semantic и memshelf search-bench. На дог-фуде из 30 запросов hit@5 вырос с 0.03 (grep) до 0.53, hit@10 — до 0.70. По #142 владелец сам заянкал релиз на PyPI, включил private vulnerability reporting, подтвердил репо на Glama и загрузил social preview. Конфликты в PR #141/#143/#144 разрешены через merge, а не rebase: force-push заблокирован классификатором авто-режима.

## Decisions
- **Семантический индекс живёт вне полки** — `~/.local/state/memshelf-mcp/semantic/<shelf-key>/index.json`, инкрементально по (mtime, size). Отклонено: индекс в `shelf/` (бинарный дифф в git, конфликт с `rebuild --check`) и векторная БД (зависимость ради 1–2 тыс. чанков).
- **model2vec `minishlab/potion-multilingual-128M`** как эмбеддер: статическая модель, без torch, мультиязычная. Отклонено: sentence-transformers (сотни МБ зависимостей) и API-эмбеддинги (полка должна работать офлайн).
- **Слияние grep + semantic через RRF** (k=60, счёт = round(1000·Σ 1/(60+rank))), пул `FUSION_POOL = 20` независимо от `max_results`. Отклонено: замена grep на семантику целиком — ни один grep-хит не должен теряться, и на бенче ни один не потерян.
- **Опциональный extra `memshelf-mcp[semantic]`** и kill-switch `MEMSHELF_SEMANTIC=off`; без model2vec поиск молча остаётся grep-only. CI ставит только `.[dev]`, реальная модель — opt-in тест по `MEMSHELF_TEST_REAL_MODEL`.
- **Управление индексом — только CLI** (`memshelf semantic build|status|drop`, `memshelf search-bench`), без новых MCP-инструментов: та же линия, что в #18.
- **#18: bare id в `memshelf_recall`, статическое зеркало и CLI-глаголы** без расширения MCP-поверхности.
- **Конфликты — `git merge origin/main`, не rebase**: force-push отклоняется классификатором авто-режима; ветка сбрасывается на origin, CHANGELOG сливается «наша запись сверху».
- **#142: релиз заянкан, а не удалён** — установленные версии и pin'ы продолжают резолвиться; уязвимости принимаются через private vulnerability reporting. Self-signed сертификат для `mcpb sign` отклонён: `mcpb verify` всё равно отвечает «not signed», нужен CA-сертификат — покупка на усмотрение владельца.
- **Полка проекта `shelf/` внутри репо** (storage plain, гард doctor + rebuild --check) — по образцу issue-kit и pii-mcp.
